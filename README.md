A tool for constructing cognitive architectures that incorporate LLMs and other models as well as memory and tools. AIArchitect is built on top of [LangChain](https://python.langchain.com/en/latest/index.html) which provides most of this functionality. The main idea of AIArchitect is to conceptualize cognitive architectures as an organization of actors, where each actor has a particular role, and to provide a simple way of building such architectures.
